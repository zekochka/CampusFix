# Контакты и доступы

## Команда проекта

### Жандарбек Ханкелді
Роль: Team Lead / Project Manager

Ответственность:

- координация команды;
- распределение задач;
- контроль сроков;
- связь с заказчиком;
- планирование;
- согласование изменений;
- объединение результатов команды.

### Амир
Роль: Business / System Analyst

Ответственность:

- сбор требований;
- описание требований;
- user stories;
- критерии приёмки;
- анализ бизнес-логики;
- поддержка backlog.

### Адилет
Роль: Backend Developer

Ответственность:

- .NET / C# backend;
- API;
- бизнес-логика;
- PostgreSQL;
- статусы;
- назначение ответственных.

### Бекзат
Роль: Frontend Developer

Ответственность:

- Angular;
- пользовательский интерфейс;
- форма создания заявки;
- список заявок;
- отображение статусов;
- интеграция с backend API.

### Нурислам
Роль: QA / Tester

Ответственность:

- test cases;
- функциональное тестирование;
- фиксация дефектов;
- регрессионная проверка;
- участие в UAT.

## Заказчик

Рысдаулет Дана — лаборант.

Роль заказчика:

- описывает текущий процесс;
- уточняет требования;
- отвечает на вопросы команды;
- даёт обратную связь;
- принимает результаты работы.
