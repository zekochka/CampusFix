# О проекте CampusFix

CampusFix — учебный IT-проект по дисциплине «Управление IT-проектами».

Система предназначена для регистрации, обработки и контроля заявок о технических и инфраструктурных проблемах в одном корпусе университета.

## Основная проблема

Сейчас сообщения о неисправностях могут передаваться через WhatsApp или напрямую сотрудникам. Из-за этого:

- обращения могут потеряться;
- одна и та же проблема может быть отправлена несколько раз;
- нет общего списка заявок;
- пользователю непонятен текущий статус;
- сложно определить, кто отвечает за конкретную проблему;
- отсутствует единая история выполненных работ.

## Цель проекта

Создать систему, в которой пользователь может:

1. сообщить о проблеме;
2. создать заявку;
3. указать аудиторию и категорию;
4. отслеживать статус;
5. видеть результат обработки.

## Основной процесс

Создана → Рассматривается → В работе → Завершена

## MVP

В первую версию входят:

- создание заявки;
- выбор аудитории;
- выбор категории;
- описание проблемы;
- прикрепление фотографии;
- просмотр заявок;
- назначение ответственного;
- изменение статуса;
- история изменений.
