# Журнал решений CampusFix

## DEC-001 — Выбор модели поставки

Дата: 29.09.2026

Решение:
Использовать гибридную модель поставки.

Причина:
У проекта фиксированный срок семестра и обязательные артефакты курса, но требования могут уточняться после интервью и обратной связи заказчика.

Связанный документ:
docs/adr/0001-model-postavki.md

---

## DEC-002 — Технологический стек

Дата: 29.09.2026

Решение:

- Frontend: Angular
- Backend: .NET / C#
- Database: PostgreSQL
- Docker
- GitHub
- GitHub Actions

Причина:
Стек соответствует компетенциям команды и подходит для учебного web-проекта.

---

## DEC-003 — Статусы заявок

Дата: 29.09.2026

Решение:

Создана → Рассматривается → В работе → Завершена

Причина:
Единая последовательность статусов должна использоваться frontend, backend и документацией.

---

## DEC-004 — Область MVP

Дата: 29.09.2026

Решение:
Первый релиз охватывает один корпус университета.

Причина:
Ограничение масштаба снижает сложность проекта и позволяет реализовать полный жизненный цикл заявки в рамках семестра.

---

## DEC-005 — Языки интерфейса

Дата: 29.09.2026

Решение:
Интерфейс проектируется с поддержкой:

- казахского;
- русского;
- английского языков.

Причина:
Проект используется в университетской среде и должен учитывать требования локализации.
